# Contributing to delphicanon

Thanks for your time! I'm glad you're interested in contributing to delphicanon.

By default, all contributions to delphicanon are welcome *within reason*. If you'd like to contribute to delphicanon, please adhere to the following guidelines:

# Content we accept

- Technical corrections
- Typographical and visual fixes
- Well scoped, well reasoned solutions to problems

# Content we do not accept

- Any and all code purely generated by an AI agent with no human oversight. See AI-POLICY.md for details on this.

# How to contribute

# Conventions to keep in mind

- delphicanon uses British spelling, meaning "colour" and "optimise", "centre" and "grey".
- Adhere to the established design style.
- All code is linted using `bun run lint` using ESLint and adheres to Kernel-style Linux spacing rules (Tabs over Spaces).

# Finishing up

Before you can submit your work as a pull request, you must run QUnit tests using `bun run test` or similar. **By submitting your work you agree to it being licensed under Zero-Clause BSD.**
